# Findex Search Engine 

> Сучасний, високопродуктивний пошуковий двигун на базі FastAPI, NumPy та BM25 з підтримкою семантичного/гібридного пошуку.

 **Живий сервіс:** `http://0.0.0.0:8000`  
 **Демонстрація:** ![Search GIF](docs/demo.gif)

### Головні показники продуктивності
* **Розмір корпусу:** 200+ документів
* **Час відповіді (p95):** < 0.001 мс
* **Максимальне прискорення (NumPy):** ~5000x–7000x порівняно з початковою реалізацією на об'єктах Python
